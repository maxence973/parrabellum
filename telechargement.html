Télécharger Parabellum

Gratuit, sans compte. Choisissez la version pour votre ordinateur ou votre téléphone.

Windows

Parabellum.exe · 48 Mo · Windows 10 et 11 (64 bits)

Télécharger pour Windows
  1. Enregistrez Parabellum.exe dans le dossier de votre choix. Il n'y a pas d'installation.
  2. Double-cliquez dessus. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même.
  3. Parabellum se lance au démarrage de Windows et reste dans la zone de notification. La croix masque la fenêtre ; un clic droit sur l'icône permet de quitter.

L'avertissement de Windows apparaît parce que le programme n'est pas signé par un éditeur reconnu. Le premier lancement prend quelques secondes.

Android

Parabellum.apk · 4,4 Mo · téléphone ou tablette Android

Télécharger pour Android
  1. Ouvrez cette page sur votre téléphone et téléchargez Parabellum.apk.
  2. Ouvrez le fichier. Android demande d'autoriser l'installation depuis votre navigateur : acceptez, puis touchez Installer.
  3. Au premier rappel, autorisez Parabellum à envoyer des notifications.

L'application n'est pas sur le Play Store : Android signale donc une source inconnue. Pour que les rappels continuent d'arriver, ouvrez l'application au moins une fois toutes les deux semaines.

Bon à savoir

Deux versions indépendantes

Les données restent sur chaque appareil. Ce que vous saisissez sur l'ordinateur n'apparaît pas sur le téléphone, et inversement.

Mettre à jour

Téléchargez la nouvelle version et remplacez l'ancienne. Vos modules, votre planning et votre historique sont conservés.

Désinstaller

Sur Windows : décochez le lancement au démarrage dans les paramètres, quittez l'application, puis supprimez l'exe et le dossier %APPDATA%\Parabellum. Sur Android : désinstallez l'application comme n'importe quelle autre.
